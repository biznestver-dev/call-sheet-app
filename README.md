# 🎬 Call Sheet Manager | Вызывной лист

Интерактивный веб-инструмент для генерации и управления вызывными листами на кинопроизводстве, сценических площадках и культурных мероприятиях.

## 🚀 Особенности
- **Интерактивный 3D-виджет космоса (Three.js):** Наглядное отображение смены дня и ночи, положения Солнца и Луны в реальном времени.
- **Интерактивная карта (Leaflet):** Быстрый выбор локаций и построение маршрутов.
- **Режим правки:** Возможность прямо на странице редактировать таймлайн, состав департаментов, контакты и данные смены.
- **Интеграция с погодой:** Автоматический или ручной расчет температуры, ветра и давления на дату смены (Open-Meteo API).
- **Экспорт и печать:** Адаптивная верстка для печати в PDF и выгрузка конфигурации в JSON.
- **Общий вызывной лист:** Supabase хранит одну общую версию и синхронизирует изменения между открытыми браузерами.

## 🛠 Технологии
- HTML5, Tailwind CSS (Dark Mode)
- JavaScript (Vanilla), Vite
- Supabase (Postgres и Realtime)
- Three.js (3D-визуализация)
- Leaflet.js (Карты)
- FontAwesome (Иконки)

## 📌 Настройка общего доступа

Без настроек Supabase приложение работает локально: данные доступны только в текущем браузере. Чтобы включить общий лист:

1. Создайте проект в [Supabase](https://supabase.com/).
2. Откройте SQL Editor проекта и выполните содержимое [`supabase/schema.sql`](./supabase/schema.sql). Таблица содержит единственный общий документ; политика разрешает анонимным посетителям читать и изменять его.
3. В настройках репозитория GitHub откройте **Settings → Secrets and variables → Actions → Variables** и создайте:
   - `VITE_SUPABASE_URL` — Project URL из Supabase;
   - `VITE_SUPABASE_ANON_KEY` — публичный `anon`/`publishable` ключ проекта.
4. В GitHub откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
5. Запустите workflow **Deploy to GitHub Pages** на вкладке **Actions** (или отправьте коммит в `main`). После успешного деплоя обновите сайт.

Если общего документа в базе ещё нет, его создаст первый посетитель сайта. Чтобы перенести свою текущую версию листа, откройте сайт первым после настройки Supabase.

Публичный ключ предназначен для браузера. **Не добавляйте `service_role`/secret key** в настройки сборки или в репозиторий. При выбранном открытом доступе любой человек, знающий URL сайта, может просматривать и менять общий лист. Изменения всего документа сохраняются целиком; при одновременном редактировании конфликт разрешается выбором версии при выходе из режима правки.

## 🧑‍💻 Локальный запуск

Требуется Node.js 22 или новее:

```sh
npm ci
npm run dev
```

Для локальной проверки общего режима скопируйте `.env.example` в `.env.local` и укажите URL и публичный ключ Supabase. Для production:

```sh
npm run build
npm run preview
```
