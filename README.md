# 🎬 Call Sheet Manager | Вызывной лист

Интерактивный веб-инструмент для генерации и управления вызывными листами на кинопроизводстве, сценических площадках и культурных мероприятиях.

## 🚀 Особенности
- **Интерактивный 3D-виджет космоса (Three.js):** Наглядное отображение смены дня и ночи, положения Солнца и Луны в реальном времени.
- **Интерактивная карта (Leaflet):** Быстрый выбор локаций и построение маршрутов.
- **Режим правки:** Возможность прямо на странице редактировать таймлайн, состав департаментов, контакты и данные смены.
- **Интеграция с погодой:** Автоматический или ручной расчет температуры, ветра и давления на дату смены (Open-Meteo API).
- **Экспорт и печать:** Адаптивная верстка для печати в PDF и выгрузка конфигурации в JSON.

## 🛠 Технологии
- HTML5, Tailwind CSS (Dark Mode)
- JavaScript (Vanilla)
- Three.js (3D-визуализация)
- Leaflet.js (Карты)
- FontAwesome (Иконки)

## 📌 Использование
Просто откройте `index.html` в любом современном браузере или запустите через Live Server в Visual Studio Code.
